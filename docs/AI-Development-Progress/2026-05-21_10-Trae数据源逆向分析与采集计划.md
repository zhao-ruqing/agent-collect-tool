## 当次已实现功能

### Trae 数据源逆向分析（二次验证，结论已修正）

经过对 Trae 安装目录 3 个层级的完整排查（`state.vscdb` K-V 库、`ModularData/ai-agent/` 模块数据、`logs/` 进程日志），确认以下可采集字段：

**一级数据源：workspaceStorage state.vscdb（SQLite K-V 库）**

| Key | 内容 | 采集值 |
|-----|------|--------|
| `memento/icube-ai-agent-storage` | 会话 ID 列表 | 所有历史 sessionId |
| `icube_session_agent_map` | sessionId → Agent 类型 | builder / dev_agent / solo_agent |
| `{userId}_ai-chat:sessionRelation:modelMap` | sessionId → 模型名 | 如 `1_-_gemini-3-flash-premium` |
| `icube-ai-agent-storage-input-history` | 用户输入历史 | prompt 文本 + 引用的文件路径 |
| `ChatStore` | 对话 UI 状态 | 轮次高度（辅助推算对话轮数） |
| `currentAgentData_{userId}` | 当前 Agent 配置 | 名称 / 类型 / 内置工具列表 |
| `workspace.json`（独立文件） | 项目路径 URI | 如 `file:///d%3A/Project/agent-collect-tool` |

**二级数据源：ModularData/ai-agent/snapshot/（Git 快照仓库）**

每个 session 对应一个目录，内部为完整 Git 仓库，通过 Tags 追踪每次对话的代码变更：

```
snapshot/<sessionId>/v2/.git/
  Tags:
    chain-start-{sessionId}           ← 对话链起点
    before-chat-turn-{turnId}         ← AI 回答前的文件状态
    toolcall-{turnId}-{callId}        ← 单次工具调用后的文件状态（每轮可有多个）
    after-chat-turn-{turnId}          ← AI 回答完成后的文件状态
```

- `git diff before-chat-turn-{id} after-chat-turn-{id}` → **获取完整代码 diff**
- `git diff before-chat-turn-{id} toolcall-{id}` → **获取单次工具调用的变更**
- 文件存在 `base/content/` 和 `disk/content/` 路径下，分别对应修改前/后

**三级数据源：renderer.log（进程日志，辅助参考）**

- `chat get_sessions` / `chat count_sessions` API 调用痕迹 → 辅助判断会话活跃时间
- `[ai-chat] initChatView` → 会话初始化时间点

**最终字段对比（二次验证确认）：**

| 数据类别 | 是否可采集 | 数据来源 | 说明 |
|---------|:---:|---------|------|
| 用户输入内容 | ✓ | vscdb input-history | 含文本 + 引用文件路径 |
| 助手回复内容 | ✗ | 仅云端 | 本地所有位置均未找到；`chatHistoryNeedToBeMigrated` 已迁移到云端 |
| 代码变更（diff） | ✓ | Git 快照 | `git diff before→after` 提取，含完整 diff skeleton |
| 代码接受/拒绝 | △ | Git 快照 | toolcall tag 含变更文件列表，但无显式 accept/reject 标记 |
| 会话元信息 | ✓ | vscdb session map | Agent 类型 + 模型名 |
| 项目路径 | ✓ | workspace.json | 含盘符+完整路径（需脱敏） |
| Git 分支 | ✗ | — | 快照为独立 Git 仓库，不含源仓库分支信息 |
| Token 精确统计 | ✗ | — | 无 token 计数字段，可从模型+轮次估算 |
| 工具调用次数 | ✓ | Git 快照 | toolcall tag 数量 = 工具调用次数 |
| 修改文件列表 | ✓ | Git 快照 | `git show --stat` 获取变更文件及增删行数 |

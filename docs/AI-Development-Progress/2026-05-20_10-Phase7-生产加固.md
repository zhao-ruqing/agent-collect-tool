## 当次已实现功能

### Phase 7.1 — Agent 加固

- Windows 服务 CWD=System32 路径修复：config.toml 和 data_dir 基于 exe 所在目录解析绝对路径，服务模式下不再因 CWD=System32 找不到配置
- 全局 panic hook：panic 发生时记录完整的错误信息和位置，写入 log::error! 和 stderr
- 崩溃自动重启：服务模式中 run_app() 异常退出后等待 5 秒自动重启，最多 5 次连续重启（防无限循环）
- Ctrl+C 优雅关闭：前台模式（agent run）通过 tokio::select! 同时监听 engine.run() 和 ctrl_c() 信号，收到 Ctrl+C 后调用 engine.shutdown() 刷新队列再退出
- HMAC 签名上报：HttpReporter 集成 HMAC-SHA256 签名，请求头携带 X-Agent-Id 和 X-Agent-Signature，签名基于请求体 + 共享密钥

### Phase 7.2 — 后端加固

- HMAC 签名验证：collect handler 改用 Bytes 提取器读取原始请求体，验证 X-Agent-Signature 头，验证失败返回 401
- 请求追踪：路由添加 TraceLayer，所有 HTTP 请求自动记录 method/uri/latency/status
- CORS 中间件：CorsLayer 允许任意来源跨域访问，支持管理后台本地开发
- AppState 扩展：新增 agent_api_secret 字段，从环境变量 AGENT_API_SECRET 读取
- Agent 注册接口真实实现：
  - POST /api/v1/agent/register：接收 agent_id/hostname_hash/os_info，生成 api_key=HMAC(agent_id, secret)，写入 agents 表
  - GET /api/v1/agent/config：从数据库查询 Agent，返回配置
  - store::agent::register()：新增函数，支持 api_key/os_info/version 写入，ON DUPLICATE KEY UPDATE
- Agent model 新增 api_key 字段
- 数据库迁移 002：messages 表添加 content TEXT 列（如不存在），agents 表添加 api_key VARCHAR(128) 列
- 配置新增 AGENT_API_SECRET 环境变量

- Agent 20 测试通过，后端 12 测试通过
- HMAC 签名验证：无签名请求 → 401，正确签名 → 200 OK
- 后端 Dashboard API 返回正常数据

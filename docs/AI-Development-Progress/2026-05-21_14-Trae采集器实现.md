## 当次已实现功能

### Phase 2.4.1 — workspace.rs 工作区发现

- 遍历 `%APPDATA%/Trae/User/workspaceStorage/` 下所有工作区目录
- 读取 `workspace.json` 获取项目路径（支持 `folder` 和 `folders[].uri` 两种格式）
- `file://` URI → 文件系统路径转换（含 URL 解码 `%3A` → `:`）
- 区分 Windows 盘符路径（`d:/...`）和 Unix 绝对路径（`/home/...`）
- 仅返回 state.vscdb 存在的工作区

### Phase 2.4.2 — vscdb.rs SQLite K-V 读取器

- `rusqlite` 只读模式打开 `state.vscdb`（不干扰 Trae 正常运行）
- 固定 key 直接读取：`memento/icube-ai-agent-storage`、`icube_session_agent_map`、`icube-ai-agent-storage-input-history`、`ChatStore`
- 动态 key LIKE 查询：`{userId}_ai-chat:sessionRelation:modelMap`、`currentAgentData_{userId}`
- 数据库被 Trae 锁定时不崩溃（返回空 + warn 日志）

### Phase 2.4.3 — parser.rs 数据解析器

- 9 个解析函数：会话列表、agent 映射、模型映射、输入历史、agent 配置、ChatStore 轮次估算
- 兼容多种 JSON 嵌套格式（数组、`{sessions:[...]}`、`{value:[...]}`、`{data:[...]}`）
- 模型映射兼容 `{"sid":"model"}` 和 `{"sid":{"model":"..."}}` 两种格式
- 单元测试 9 个（覆盖空数据、数组、嵌套、agent config、输入历史）

### Phase 2.4.4 — snapshot.rs Git 快照解析器

- 使用 `git2` 打开快照 Git 仓库，遍历 tags
- Tag 分类：`chain-start-*`、`before-chat-turn-*`、`after-chat-turn-*`、`toolcall-*`
- `diff_between_tags`：使用 `git2::Patch::from_diff` 逐文件生成统一 diff 文本
- 行数统计通过 `Patch::line_stats()` 获取
- 路径标准化：去除 `base/content/`、`disk/content/` 前缀
- 按轮次配对 before/after tags（`group_turn_pairs`）
- 单元测试 3 个（tag 分类、turn_id 提取、路径标准化）

### Phase 2.4.5 — collector.rs TraeCollector

- 实现 `Collector` trait（name/is_installed/is_running/collect_incremental/reset_cursor）
- 采集流程：发现工作区 → vscdb 增量检测（文件 mtime）→ 读取 AI 数据 → 解析 → 生成 RawEvent
- 会话记录：从 session list 构建 `SessionRecord`
- 对话记录：从 input-history 构建 `MessageRecord`（仅用户侧，content 估算 token）
- 代码变更：从 Git 快照 before→after diff 构建 `CodeEditRecord`
- 增量：vscdb 按文件修改时间增量，快照按已处理 tag 集合去重
- 错误隔离：任何子模块失败不影响其他数据采集

### Phase 2.4.6 — 集成注册

- `collector/mod.rs`：添加 `pub mod trae;`
- `main.rs`：当 `config.tools` 包含 `"trae"` 时自动注册 TraeCollector
- `config.rs`：新增可选 `trae_data_dir` 配置项
- `Cargo.toml`：新增 `rusqlite 0.31 (bundled)` + `git2 0.19` + `urlencoding 2.1` 依赖

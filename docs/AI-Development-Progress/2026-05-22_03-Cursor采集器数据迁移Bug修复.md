# Cursor 采集器数据迁移 Bug 修复 — 2026-05-22 19:46

## 问题发现

用户报告 agent 服务"好像不会自动收集"，实际运行时发现 Cursor 采集器上报的数据中缺少最新的对话。经深入排查发现一个 Bug 和一个设计缺陷。

## Bug: composerData 迁移后 allComposers 为空

### 根因

Cursor 在某个版本后对 `composer.composerData` 进行了数据迁移：
- **迁移前**: `allComposers` 数组包含完整会话列表
- **迁移后**: `hasMigratedComposerData: true`，`allComposers` 为空数组，会话 ID 仅存在于 `selectedComposerIds` 和 `lastFocusedComposerIds` 中

原解析器 `parse_composer_data()` 只读 `allComposers`，迁移后的工作区返回 0 个 composer → 采集器跳过整个工作区。

### 验证

`anqigou-app` 工作区（hash `3c970506...`）：
- `~/.cursor/projects/d-Project-anqigou-app/agent-transcripts/` 中有新的 transcript 文件（`8cc6a9e7-...`，2 行，2026-05-22 11:31 创建）
- vscdb 中 `allComposers: []`，`hasMigratedComposerData: true`，`selectedComposerIds: ["8cc6a9e7-..."]`
- 修复前：采集器报告 0 个 composer，工作区无事件产出
- 修复后：成功采集 2 条事件

## 三处修复

### 修复 #1: parser.rs — 迁移数据合成 ComposerEntry

**文件**: `agent/src/collector/cursor/parser.rs`

`parse_composer_data()` 新增逻辑：当 `allComposers` 为空但 `selectedComposerIds` 非空时，从 ID 列表合成 `ComposerEntry`（字段为 None，transcript 数据补充内容）。

```rust
if parsed.all_composers.is_empty() && !parsed.selected_composer_ids.is_empty() {
    let mut seen = std::collections::HashSet::new();
    for id in parsed.selected_composer_ids.iter()
        .chain(parsed.last_focused_composer_ids.iter())
    {
        if seen.insert(id) {
            parsed.all_composers.push(ComposerEntry { composer_id: id.clone(), .. });
        }
    }
}
```

### 修复 #2: collector.rs — transcript 目录 mtime 检测

**文件**: `agent/src/collector/cursor/collector.rs`

新增 `latest_transcript_mtime()` 自由函数和 `projects_modified()` 方法：扫描 `~/.cursor/projects/*/agent-transcripts/` 目录树，跟踪最新 transcript 文件的 mtime。

### 修复 #3: collector.rs — 双重变更检测

**文件**: `agent/src/collector/cursor/collector.rs`

`collect_incremental()` 中工作区处理条件从单向检测变为双重检测：

```rust
// 修复前：仅检查 vscdb mtime
if !self.vscdb_modified(ws) { continue; }

// 修复后：同时检查 transcript 目录 mtime
let projects_changed = self.projects_modified();
if !self.vscdb_modified(ws) && !projects_changed { continue; }
```

新增 `update_projects_cursor()` 方法，采集完成后更新 `projects_last_mtime` 游标。

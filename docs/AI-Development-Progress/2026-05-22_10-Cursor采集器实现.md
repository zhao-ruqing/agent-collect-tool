### 采集数据流

```
discover_workspaces(Cursor/User/)  ← 复用 trae::workspace
        │
        ▼
VscDbReader::read_ai_data()
  ├─ composer.composerData  → ComposerEntry[] (composerId, mode, timestamps, line stats)
  └─ aiService.generations  → GenerationEntry[] (UUID, type, timestamp)
        │
        ▼
find_transcript_dir(composerId)  ← 扫描 ~/.cursor/projects/*/agent-transcripts/
        │
        ▼
read_transcript_lines()  ← JSONL: role + message.content[] (text/tool-call/tool-result)
        │
        ▼
RawEvent::Session + RawEvent::Conversation + RawEvent::CodeEdit + RawEvent::Action
```

### 设计决策

1. **transcript 匹配**：通过扫描 `~/.cursor/projects/` 下所有 `agent-transcripts/<composerId>/` 目录按 composerId 匹配，避免路径编码歧义
2. **游标策略**：双重游标 — workspace mtime（增量扫描 vscdb）+ transcript 行偏移量（增量读取 JSONL）
3. **代码复用**：直接复用 `trae::workspace::discover_workspaces`（工作区发现逻辑完全一致）
4. **generations 关联**：按时间范围将 generation 事件归入对应 composer 会话
5. **代码变更**：从 composerData 的 `totalLinesAdded/Removed` 生成摘要级 CodeEdit，无完整 diff
